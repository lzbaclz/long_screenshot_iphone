# 续页 / Longlet 0.1.7（8）免费正式版本重新送审

日期：2026-09-19。**13:45（Europe/London，12:45 UTC）已正式重新提交 0.1.7（8），Apple 状态为“等待审核”。** 已完成新构建上传、版本关联、中英文资料及审核备注更新；这不代表已通过审核或已上架。

## 原因与修复

0.1.5（6）因 2.1(b) 被拒。Apple 原始截图显示设置页的 `Restore purchases`，但后台没有内购商品。此前只关闭新购买入口，保留了恢复购买、权益验证和相关说明，导致界面与发布配置不一致。

本版基于最新 0.1.6（7）源码，保留其切换目标内容后重新确定起点的修复：

- 删除购买、恢复、商品加载及 StoreKit 权益监听代码，删除 `ProProductIdentifier`；将原 `PurchaseStore` 改为只管理本机免费额度的 `ExportQuotaStore`。
- 设置页移除恢复购买和无限解锁状态，版本号显示 `0.1.7`；中英文移除 Beta／内测版标记及未使用的购买文案。隐私页改为解释导出记录。
- 正式使用规则保持每周 50 个新作品，按设备本地 ISO 周一更新。已导出作品可重复保存和分享，失败／取消不计次；达到额度后捕捉、查看和编辑仍可使用。
- 保留原 `successfulCaptureExports.v1` 本机记录键，升级不会清空已有导出次数或作品；没有引入账号、云端计数或支付服务。
- 同步 GitHub Pages 中英文隐私政策、支持页和官网额度说明，清理既有 Pro／恢复购买的旧描述。托管仍为仓库 GitHub Pages。
